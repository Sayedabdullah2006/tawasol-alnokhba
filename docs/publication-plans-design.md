# خطة النشر اليومية

لوحة تحرير لأول سعودي هدفها مراجعة خطة مؤرخة ومادّتين يوميًا؛ ليست شاشة توليد حر.

الألوان داخل اللوحة: غابي #15432F، داكن #0C211B، ليموني #D2D869، عاجي #FCFAF3، رملي #E8DECC، نص ثانوي #53645A. عناوين Almarai Bold المحلية، ونصوص متصلة متوافقة مع لوحة الإدارة. محاذاة من اليمين، والأوقات والروابط LTR.

اسم الخطة ومداها ثم أربعة تبويبات. اليوم عمودان تحريريّان بوقتين واضحين وصور فعلية. الخطة جدول يومي بأنواع ملوّنة وتفاصيل قابلة للفتح. الأرشيف مجموعات قابلة للبحث. المصدر قائمة أخبار ومؤشر مزامنة. على الجوال عمود واحد وتمرير أفقي للجدول دون إخفاء الإجراءات.

الألوان لتمييز الأنواع والحالات؛ واجهة مسطحة بفواصل هادئة دون تدرجات أو إحصاءات مختلقة. الفراغ يرشد إلى إعداد الخطة، ولا يملأ بمواد وهمية. الأرشيف للقراءة فقط؛ النسخ ينتج مسودة وفق الخطة. الاعتماد لا ينشر أو يجدول. استثناء 21 نوفمبر بيانات مؤرخة مستقلة؛ المرجع المشترك لا يتغير.
