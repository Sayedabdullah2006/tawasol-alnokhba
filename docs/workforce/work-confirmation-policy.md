# تأكيد استمرار العمل

- الأوقات اليومية بتوقيت الرياض: 11:00 و13:00 و15:00؛ بحد أقصى ثلاثة تأكيدات.
- عند تسجيل الحضور تختار الجلسة الموعد القادم فقط؛ لا تطلب المواعيد التي مضت، ولا تتكرر بعد إعادة تسجيل الحضور.
- مهلة الرد خمس دقائق. إذا لم يؤكد الموظف، تغلق الجلسة عند موعد التأكيد، لا عند نهاية المهلة.
- أثناء الاستراحة لا يظهر التأكيد. عند الاستئناف يبقى الموعد القادم، أو يصبح التأكيد مستحقًا فور العودة إذا مضى موعده، مع مهلة جديدة لخمس دقائق.
- لا يُنشأ تأكيد رابع؛ الساعة 17:00 نهاية للجلسة فقط.
- مراقبة اتصال الجهاز والاستراحة المدفوعة ونهاية الدوام تبقى مستقلة عن عدد التأكيدات.
- السجلات التاريخية المغلقة لا تتغير. يطبق الجدول على الجلسات الجديدة، والجلسة المفتوحة تنتقل إليه عند التأكيد التالي.

التحقق المعزول: `tests/workforce-daily-confirmations.test.mjs` يغطي نور ومنوه، وثلاثة تأكيدات في يوم كامل، والدخول المتأخر، والانقطاع، وإعادة الحضور، والاستراحة المتزامنة مع التأكيد، وصلاحية الدالة الداخلية. لا يستخدم بريدًا أو شبكة أو بيانات إنتاج.
