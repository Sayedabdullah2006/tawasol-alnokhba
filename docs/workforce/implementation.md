# منظومة موظفي تواصل النخبة — وثيقة التنفيذ

## مرفقات المهام والتسليمات

الترحيل `20261018104324_workforce_task_attachments.sql` يضيف حاوية خاصة `workforce-task-files` دون سياسات وصول مباشر للعميل، وبصمةSHA-256 وغرض المرفق، وجدول ربط ثابت لكل محاولة تسليم تحتRLS. يلتقط أمر التسليم المرفقات المحددة ضمن المعاملة نفسها؛ أي ملف مؤرشف أو غريب أو مكرر يلغي العملية كاملة. أوامر المرفقات تعيد فحص المنفذ والتكليف وحالة المهمة مع ترتيب قفل اللوحة ثم المهمة، وتمنع تغيير ملفات تسليم محفوظ.

واجهات رفع متعددة الأجزاء محدودة الحجم فعليًا حتى مع النقل المجزأ، وفحص محتوى الصور وPDF وبنية أسماءZIP/Office والنصUTF-8. كل محاولة رفع متزامنة تملك مسار كائن مستقل، ومفتاح الملف وبصمته يمنعان تكرار المرفق أو استبداله عند إعادة المحاولة؛ تنظيف الكائن الخاسر بعد التحقق من عدم ربطه فقط. نتيجة شبكة مجهولة قد تترك كائنًا خاصًا غير مرتبط بدل المجازفة بحذف ملف محفوظ؛ تنظيف دوري لهذه الحالات لم يُجدول.

معاينةPDF تستخدم `pdfjs-dist` بإصدار مثبت6.4.299 وتحمّل المكتبة عند فتح المعاينة فقط. تُرسم صفحة واحدة مع تكبير وتنقل ونص لقارئ الشاشة، دون تشغيل سكربتات المستند أو روابطه. `scripts/prepare-workforce-pdf.mjs` يجهزworker والخطوط وCMaps وWASM وICC وترخيصApache محليًا عبرpredev/prebuild؛ استخدم `npm run dev` أو `npm run build` لتجهيز هذه الأصول. لا تُرسل الملفات إلى عارض خارجي. مثال المكتبة الرسمي: https://mozilla.github.io/pdf.js/examples/ .

التنزيل والمعاينة يمران عبرAPI بهوية المستخدم ثمRLS للمهمة قبل قراءةStorage بالخدمة، دونURL موقع أو عام. استجاباتprivate/no-store وnosniff وتسمية تنزيلUTF-8؛ المعاينة مقتصرة على الصور وPDF، وبقية الأنواع تنزيل فقط. عرض المرفقات مقسم20، واختيار التسليم يحفظ التحديد عبر الصفحات. الحدود الحالية4MiB للملف،20 للمحاولة/دفعة الاختيار و100 مرفق نشط.

## تحديث لاحق — لوحة الأدمن والمستحقات الشهرية

مساحة `/admin/workforce` لها تنقل مستقل عن إدارة العملاء. يجمع `wf_admin_dashboard` بيانات الأداء دون حقول مالية، بصلاحية الأدمن وRLS، وتفتح تفاصيل المهام والاعتماد وكشف الموظفة داخل الصفحة. انتقلت إدارة الحسابات إلى `/admin/workforce/employees`.

جداول `wf_monthly_payroll` و`wf_payroll_payments` و`wf_payroll_events` مع أمر `wf_payroll_command` توفر تقديرًا شهريًا واعتمادًا وتوثيق دفعات خارجية وسجلًا غير قابل للتحرير من العميل. الأمر محصور في service_role ويتحقق من الأدمن صراحة، مع نسخة تفاؤلية ومفتاح إعادة محاولة. SELECT للأدمن أو صاحبة الكشف النشطة فقط، والكتابة عبر API الأدمن. النسب من أساس يدخله الأدمن لكل مهمة أو مرجع صفقة، والحساب والتقريب في Postgres. لا تحويل بنكي ولا خصومات نظامية تلقائية أو حساب نسبي للأيام.

تظهر المستحقات الخاصة في داشبورد الموظفة و`/employee/finance/overview`. تفتح روابط الكشوف والعمولات الشاشة نفسها. الإشعارات لكل مستلمة على حدة. لا تمنح قراءة مهام الفريق وصولًا إلى أي بيانات مالية لزميلة.

## التصميم
- عقد العلاقة بين الدورين موثق تفصيليًا في `role-workflows.md`: من ينشئ ويعدل ويقرر، ما ينتقل بين الطرفين، أثر القرار، ضوابط القبول، والنواقص الفعلية. تُختبر دورة العمل كاملة، ولا يعتبر اكتمال شاشة منفردة قبولًا.
- توجيه المستخدم الأحدث: تثبيت الهيكلية أولًا قبل مواصلة التوسع الوظيفي. المرجع `architecture.md`؛ قائمة الموظف 7 أقسام رئيسية و34 صفحة فرعية و65 ارتباطًا، مع داشبورد مستقلة. خمسة أنواع صفحات متاحة فعليًا، والبقية معاينة واضحة للهيكلية وليست موديولات مكتملة.
- مركز الطلبات شامل الإجازات والاستئذان والعمل عن بعد والتعويضات والسلف والخطابات والتصحيحات والاعتراضات وتعديل البيانات والطلب العام. تعديل البيانات تحت `/employee/requests/profile-change` فقط.
- عُزل غلاف الموظف وغلاف إدارة الفريق عن ترويسة الموقع العام وتذييله والعروض. `/employee` الآن داشبورد؛ الملف تحت `/employee/profile`، والمستندات وبيانات الصرف تحت قسميهما.
- صفحات الإدارة تحت `/admin/workforce`؛ الموظف تحت `/employee`.
- API تحت `/api/workforce`، تحقق هوية على كل عملية، ثم RLS على البيانات.
- منع تغيير الدور من جلسات العملاء والموظفين في قاعدة البيانات حتى عبر REST مباشرة.
- الموظفون والأقسام منفصلون عن الملفات المالية والملاحظات الإدارية والمستندات الخاصة.
- الكتابة المالية لاحقًا بمعاملات SQL وقيم هللات صحيحة، وسياسات ذات إصدارات وتواريخ سريان.
- تحديثات متزامنة: رقم إصدار متوقع؛ رد 409 بدل الكتابة فوق تغييرات مستخدم آخر.
- الملفات خاصة، وروابط مؤقتة بعد التحقق، وعدم حذف التاريخ عند إنهاء الموظف.
- إجراءات مستقلة قابلة لإعادة المحاولة مع مفتاح عدم تكرار حيث توجد آثار متعددة أو مالية.
