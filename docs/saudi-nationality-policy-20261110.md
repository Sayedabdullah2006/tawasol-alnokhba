# سياسة ذكر الجنسية في المحتوى

أُلغي شرط إثبات الجنسية السعودية قبل التوليد في استديو الطلبات والاستديو المستقل والخطط التحريرية والنشرة والحملات. يمكن إعداد النصوص والتصاميم وتعديلها دون طلب إثبات الجنسية أو استبعاد المواد بناءً عليها.

تُذكر الجنسية في المحتوى فقط إذا وردت صراحة في المادة وكانت ذات صلة بالخبر.
