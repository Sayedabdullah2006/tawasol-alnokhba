# إدارة الكتالوج الديناميكي

المصدر الجاري للباقات الفردية وأسعار أنواع الأخبار والإضافات هو الإصدار المنشور من قاعدة بيانات تواصل النخبة. جدول v3 السابق هو نقطة التهيئة فقط. لا يلزم نشر برمجي لتعديل المزايا والأسعار من لوحة الإدارة.

## التشغيل

ادخل /admin/packages بحساب مسؤول. عدّل الاسم والوصف والإتاحة والترتيب وطريقة التسعير والقنوات والمزايا والميزانية المشمولة والخدمات الإضافية. أسعار أنواع الأخبار والإضافات في تبويبين مستقلين.

اضغط حفظ المسودة ثم راجع معاينة الأسعار. حفظ المسودة لا يغير المعروض للعميل. اضغط نشر الباقات لتفعيل نسخة متكاملة دفعة واحدة. إذا عدّل مسؤول آخر المسودة، تعاد 409 CATALOG_CONFLICT لحماية تعديله. سجل النشر يحتفظ بالإصدارات؛ تحميل إصدار سابق يجعله مسودة، ويحتاج نشرًا جديدًا لتفعيله.

المبالغ في لوحة الإدارة بالريال مع دعم هللتين عشريتين. يجب ألا تتجاوز الميزانية الإعلانية أقل سعر ممكن للباقة. الميزانية مشمولة ولا تخصم معها مرة ثانية. حدّث نص المزايا عند تغيير القنوات أو الميزانية حتى لا يختلف الوعد المكتوب عن إعداد التسعير. حقول عدد المخرجات تحدد عدد روابط التسليم المستقلة؛ ومنها إعلانات التوظيف.

## العرض والتسعير

- صفحة الأسعار تقرأ النسخة المنشورة عند فتحها، وتتحدث وهي مفتوحة خلال 60 ثانية أو عند العودة للنافذة. نموذج الطلب يستخدم البيانات نفسها ويتحقق من إصدارها قبل الإرسال.
- GET catalog الموقّع لأول سعودي يقرأ النسخة المنشورة نفسها. version نص معرّف لا يفسره العميل ولا يثبته في الكود. published_at وقت النشر، وcache_ttl_seconds أقصى مدة لكاش العرض.
- ترتيب packages هو ترتيب العرض. الباقات الموقوفة لا تعود للطلبات الجديدة. channels مصفوفة تعني قنوات ثابتة؛ null تعني أن العميل يختار channel_count قنوات مختلفة. required_category تحدد الفئة اللازمة؛ لا تربط السلوك بالاسم التجاري.
- features نصوص العرض المشتقة من benefits المشمولة. benefits عناصر للمقارنة تحمل id وlabel وvalue وincluded وquantity اختياريًا. اعرض النص كنص ولا تنفذه كـHTML.
- جميع الأموال في API الشريك أعداد صحيحة بالهللة. fixed_price سعر مستقل، surcharge زيادة على نوع الخبر، وstarts_from سعر بداية للعرض فقط. السعر الملزم من quotes، ويشمل اختيار الإضافات والخصم المعتمد مركزيًا.
- أرسل catalog_version في إنشاء quotes. عند اختلاف الإصدار تحصل على 409 CATALOG_CHANGED. أعد الكتالوج والسعر واعرضهما للعميل قبل المتابعة، دون إعادة إرسال شراء تلقائي بسعر مختلف.
- يحتفظ العرض لمدة صلاحيته ثم الطلب بـpackage_snapshot القديمة ومبالغها. إيقاف الباقة أو تعديلها لا يعيد تسعير عرض صالح أو طلب سابق. الفاتورة والمخرجات تستندان إلى النسخة المحفوظة.
- تعذر تحميل المصدر لا يستبدله تسعير ثابت في الكود. لا تنشئ طلبًا أو تؤكد سعرًا عند 503؛ أبقِ الحالة قابلة للتحديث والمحاولة.

## الحماية والنطاق

الجداول لا تمنح anon أو authenticated وصولًا مباشرًا. القراءة المعلنة تمر بالخادم. التعديل يتطلب جلسة مسؤول والتحقق من Origin. جدول الإصدارات يمنع service_role من UPDATE وDELETE، ووظائف النشر SECURITY INVOKER مع search_path ثابت واستدعاء للخادم فقط.

هذه الإدارة للباقات الفردية الجديدة ومسارات API المقابلة لها. الحملات والعضويات والجهات والمسارات اليدوية لها آليتها الحالية. ملف bootstrap يستخدم لتهيئة أول إصدار فقط، ولا يستخدم كاحتياط للتسعير أثناء التشغيل.

أصل الإدارة الافتراضي هو NEXT_PUBLIC_SITE_URL. CATALOG_ADMIN_ORIGIN اختيار خادمي لتحديد أصل لوحة الإدارة في بيئة اختبار مستقلة، ولا يحتاجه أول سعودي.
